# Anthony Santos - Portfolio Website

A beautiful static website built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Features

- ✨ Responsive design that works on all devices
- 🎨 Modern and clean UI with smooth animations
- 📱 Mobile-friendly navigation
- 💬 Contact form with validation
- ⚡ Smooth scrolling navigation
- 🎯 Intersection Observer for fade-in animations

## Sections

1. **Header & Navigation** - Sticky navigation bar with smooth scrolling
2. **Hero Section** - Eye-catching landing area with call-to-action button
3. **About Section** - Personal introduction and skills showcase
4. **Projects Section** - Portfolio of completed projects
5. **Contact Section** - Contact form for inquiries
6. **Footer** - Copyright and closing information

## Files

- `index.html` - Main HTML structure
- `style.css` - All styling and animations
- `script.js` - Interactive features and smooth scrolling
- `README.md` - This file

## How to Use

1. The website is automatically deployed to GitHub Pages
2. Access it at: `https://kenny0537YAhoo.github.io/anthonysantos`
3. Customize the content in `index.html` with your own information
4. Modify colors and styles in `style.css`
5. Add more functionality in `script.js`

## Customization

### Change Your Name
Replace "Anthony Santos" throughout the HTML file with your name.

### Update Projects
Edit the project cards in the Projects section with your own projects.

### Modify Colors
Edit the color values in `style.css` (look for hex colors like `#667eea`).

### Add More Sections
Duplicate a section in `index.html`, update the HTML, and add styles in `style.css`.

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript
- GitHub Pages
